## 1. 振幅分布策略 (Amplitude Distribution Strategy)

### 📌 策略意图
本策略基于**“历史振幅统计”**与**“预期收益最大化”**原则。
核心逻辑是：**撸短的预期收益 = 概率 * 赔率 * 衰减因子**。
通过统计历史数据的振幅概率分布，结合杠杆赔率，计算出每层网格的最佳资金权重，以实现长期期望收益最大化。

### ⚙️ 资金分配逻辑 (统计权重)

| 网格层级 (跌幅) | 资金权重 (Weight) | 计算依据 (概率 * 收益 * 衰减) |
| :--- | :--- | :--- |
| **第 1 层** (跌 1%) | **36%** (0.36) | 概率 36% |
| **第 2 层** (跌 2%) | **32%** (0.32) | 概率 24% |
| **第 3 层** (跌 3%) | **21%** (0.21) | 概率 16% |
| **第 4 层** (跌 4%) | **9%** (0.09) | 概率 9% |
| **第 5-10 层** | **0%** | 低概率区间，正常行情下不配置资金 |

## 2. 马丁格尔策略 (Martingale Strategy)

### 📌 策略意图
本策略的核心思想是**“左侧交易”**和**“倒金字塔加仓”**。
在震荡下行的行情中，利用价格下跌逐步建立仓位，且随着跌幅加深，加大买入力度（加仓权重增加）。这能显著拉低持仓均价，使得价格只需出现较小的反弹即可整体获利或解套。

### ⚙️ 资金分配逻辑 (倒金字塔)
| 网格层级 (跌幅) | 资金权重 (Weight) | 意图 |
| :--- | :--- | :--- |
| **第 1-3 层** (跌 1%-3%) | **5%** (0.05) | **轻仓试探**：防止在下跌初期过早消耗子弹，保留实力。 |
| **第 4-7 层** (跌 4%-7%) | **10%** (0.10) | **正常补仓**：随着价格进入价值区间，开始加大投入。 |
| **第 8-10 层** (跌 8%-10%) | **15%** (0.15) | **重仓抄底**：在深跌区域重拳出击，摊薄成本，博取大反弹。 |

## 3. 概率分布策略 (Probability Strategy)

### 📌 策略意图
本策略的核心思想是**“右侧思维”**和**“大概率优先”**。
基于统计规律，绝大多数有效波动集中在 **1% - 2%** 的微小幅度内。因此，本策略将主力资金集中在最容易触发的浅层网格，追求高频成交和资金利用率。

### ⚙️ 资金分配逻辑 (正态分布/高频优先)
| 网格层级 (跌幅) | 资金权重 (Weight) | 意图 |
| :--- | :--- | :--- |
| **第 1-3 层** (跌 1%-3%) | **15%** (0.15) | **重仓出击**：这是最高频的波动区间，投入重兵以获取最大化的刷单收益。 |
| **第 4-7 层** (跌 4%-7%) | **10%** (0.10) | **辅助防守**：应对中等幅度的波动，保持在场。 |
| **第 8-10 层** (跌 8%-10%) | **5%** (0.05) | **防守挂单**：发生概率极低（黑天鹅），仅保留少量资金防守，避免资金闲置。 |
